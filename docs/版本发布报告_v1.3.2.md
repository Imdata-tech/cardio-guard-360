## 🎯 版本概述

v1.3.2版本实现了**WebSocket实时ECG数据推送**功能,完成了从后端到前端的完整实时数据链路。通过WebSocket协议,系统能够以毫秒级延迟将ECG波形数据从后端推送到前端,实现真正的心电图实时监测。

### 核心价值

✅ **实时性**: 毫秒级数据推送延迟  
✅ **稳定性**: 自动重连机制保障连接可靠性  
✅ **扩展性**: 支持多数据类型推送 (心率、ECG、血压等)  
✅ **测试友好**: 内置ECG数据模拟器,无需真实设备即可测试

## ✨ 核心功能

### 1. WebSocket实时通信

#### 1.1 连接管理
- 基于userId的会话管理
- 并发连接支持 (ConcurrentHashMap)
- 连接状态追踪和日志记录

#### 1.2 多数据类型推送
- `realtime-data`: 实时心率等生理参数
- `ecg-data`: ECG波形数据点
- `broadcast`: 广播消息 (系统公告、预警)

#### 1.3 消息格式标准化
```json
{
  "type": "ecg-data",
  "timestamp": 1712995200100,
  "data": {
    "timestamp": 1712995200100,
    "voltage": 0.523,
    "heartRate": 72.5,
    "sampleRate": 250
  }
}
```

### 2. ECG数据模拟服务

#### 2.1 逼真的ECG波形生成
- **P-QRS-T复合波模拟**
  - P波: 心房去极化
  - QRS波: 心室去极化 (主峰)
  - T波: 心室复极化
  
- **生理参数模拟**
  - 基础心率: 72 bpm (±5波动)
  - 采样率: 250 Hz
  - 电压范围: -2mV ~ +2mV
  - 随机噪声: ±0.05mV

#### 2.2 定时推送机制
- Spring `@Scheduled` 定时任务
- 推送频率: 100ms (演示模式,实际应为4ms)
- 多用户并发支持

#### 2.3 启停控制API
```http
POST /api/ecg/simulation/start?userId=1
POST /api/ecg/simulation/stop?userId=1
```

### 3. 前端WebSocket集成

#### 3.1 连接管理
- 自动建立WebSocket连接
- 连接状态可视化 (已连接/未连接)
- 组件卸载时优雅关闭连接

#### 3.2 消息处理
- 消息类型路由 (`ecg-data`, `realtime-data`)
- JSON解析和错误处理
- ECG数据点实时更新波形图

#### 3.3 断线重连机制
- **指数退避策略**: 3s → 6s → 9s → 12s → 15s
- **最大重试次数**: 5次
- **智能判断**: 正常关闭不重连

#### 3.4 数据缓冲
- 保持最近500个数据点
- 自动清理旧数据防止内存泄漏
- 实时更新ECharts图表

**波形算法:**
```java
// 基础正弦波 (模拟心率节奏)
double baseWave = Math.sin(2 * Math.PI * 1.2 * time);

// QRS复合波 (高斯函数模拟尖峰)
if (phase > 0.45 && phase < 0.55) {
    qrsWave = 1.5 * Math.exp(-Math.pow((phase - 0.50) * 80, 2));
}

// T波
if (phase > 0.70 && phase < 0.90) {
    tWave = 0.4 * Math.exp(-Math.pow((phase - 0.80) * 30, 2));
}

// 最终电压
double voltage = baseWave * 0.1 + qrsWave + tWave + noise;
```

// 建立连接
const connectWebSocket = () => {
  ws = new WebSocket(`ws://localhost:8080/ws/monitor?userId=${userId}`)
  
  ws.onopen = () => { /* 连接成功 */ }
  ws.onmessage = (event) => { /* 处理消息 */ }
  ws.onerror = (error) => { /* 错误处理 */ }
  ws.onclose = (event) => { /* 尝试重连 */ }
}

// 处理ECG数据
const handleEcgData = (data: any) => {
  ecgData.value.push(data.voltage)
  if (ecgData.value.length > 500) ecgData.value.shift()
  currentHeartRate.value = Math.round(data.heartRate)
}

// 断线重连
const attemptReconnect = () => {
  reconnectAttempts++
  setTimeout(() => connectWebSocket(), 3000 * reconnectAttempts)
}
```

```

## 🐛 已知问题

### 1. 采样率限制

**问题描述:**
当前ECG模拟服务的推送频率为100ms (10Hz),低于真实ECG设备的250Hz。

**影响:**
- 波形细节不够精细
- QRS波峰可能不够尖锐

**解决方案:**
- 生产环境应使用真实ECG设备
- 或调整`@Scheduled(fixedRate = 4)`达到250Hz
- 注意: 高频推送会增加网络和CPU负载

### 2. 前端性能优化

**问题描述:**
当数据量较大时,ECharts渲染可能出现卡顿。

**临时方案:**
- 保持500个数据点上限
- 使用`showSymbol: false`
- 启用`throttle`节流

**长期方案:**
- 使用WebWorker进行数据处理
- 采用Canvas直接绘制
- 实现数据降采样算法

### 3. 缺少压力测试

**问题描述:**
未进行多用户并发压力测试。

**计划:**
- v1.3.3版本补充压力测试
- 目标: 100+并发用户
- 工具: JMeter / k6

### 1. 逼真的ECG波形算法

**创新点:**
- 使用高斯函数模拟P-QRS-T复合波
- 相位归一化确保波形周期性
- 添加随机噪声提高真实感

**效果:**
```
电压(mV)
  1.5 |        R
      |       / \
  1.0 |      /   \
      |     /     \    T

      |   /         \/   \
  0.0 |--P----------S-----\----
      |                    \
 -0.5 |          Q          \
      |__________________________ 时间
```

### 2. 指数退避重连策略

**优势:**
- 避免频繁重连导致服务器压力
- 逐步增加重试间隔 (3s → 15s)
- 平衡用户体验和资源消耗

**实现:**
```typescript
const delay = 3000 * reconnectAttempts // 3, 6, 9, 12, 15秒
setTimeout(() => connectWebSocket(), delay)
```

### 3. 通用消息推送框架

**设计思想:**
- 提取`pushRealtimeData()`通用方法
- 支持动态消息类型
- 易于扩展新数据类型 (血压、血氧等)

**扩展示例:**
```java
// 未来可轻松添加
public static void pushBloodPressure(Long userId, Object bpData) {
    pushRealtimeData(userId, "blood-pressure", bpData);
}
```

### 4. 优雅的资源管理

**实践:**
- `@PreDestroy`清理模拟状态
- `onUnmounted`关闭WebSocket
- 定时器清理防止内存泄漏
