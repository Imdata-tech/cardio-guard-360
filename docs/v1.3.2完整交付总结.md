## 🚀 部署和使用指南

### 1. 启动后端服务

```bash
cd cardio-guard-backend
mvn spring-boot:run
# 访问 http://localhost:8080/api/swagger-ui.html
```

### 2. 启动前端开发服务器

```bash
cd cardio-guard-frontend
npm install  # 首次需要安装依赖
npm run dev
# 访问 http://localhost:3000
```

### 3. 测试WebSocket实时ECG功能

1. **登录系统**
   - 访问 http://localhost:3000/login
   - 使用测试账号: patient1 / 123456

2. **进入ECG页面**
   - 点击侧边栏 "ECG心电图"
   - 或直接访问 http://localhost:3000/ecg

3. **观察连接状态**
   - 右上角应显示 "已连接" (绿色)
   - 如显示 "未连接",检查后端是否启动

4. **开始记录**
   - 点击"开始记录"按钮
   - 后端自动启动ECG模拟
   - 观察波形图实时更新
   - 心率数值动态变化

5. **测试重连**
   - 停止后端服务 (Ctrl+C)
   - 观察连接状态变为 "未连接"
   - 重启后端服务
   - 等待自动重连 (最多15秒)

6. **停止记录**
   - 点击"停止记录"按钮
   - 波形停止更新
   - 后端模拟服务停止
