## 🚀 部署和使用指南

### 1. 启动后端服务

```bash
cd cardio-guard-backend
mvn spring-boot:run
# 访问 http://localhost:8080/api/swagger-ui.html
```

### 2. 启动前端开发服务器

```bash
cd cardio-guard-frontend
npm install  # 首次需要安装依赖
npm run dev
# 访问 http://localhost:3000
```

### 3. 测试ECG功能

1. **登录系统**
   - 访问 http://localhost:3000/login
   - 使用测试账号: patient1 / 123456

2. **进入ECG页面**
   - 点击侧边栏 "ECG心电图"
   - 或直接访问 http://localhost:3000/ecg

3. **测试记录功能**
   - 点击"开始记录"按钮
   - 观察波形图实时更新
   - 点击"停止记录"按钮

4. **测试AI分析**
   - 确保有ECG数据后
   - 点击"AI 分析"按钮
   - 查看分析结果展示

5. **测试报告功能**
   - 在历史记录表格中
   - 点击"查看报告" - 新窗口打开
   - 点击"下载" - 下载.md文件
