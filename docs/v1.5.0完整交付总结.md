### 2. 数据库设计与初始化

#### 2.1 数据库表结构

**ecg_lead_config表:**
```sql
CREATE TABLE ecg_lead_config (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    lead_name VARCHAR(10) NOT NULL UNIQUE,
    lead_type VARCHAR(20) NOT NULL,
    display_color VARCHAR(20) DEFAULT '#0000FF',
    display_order INT DEFAULT 0,
    is_default TINYINT DEFAULT 1,
    description VARCHAR(255)
);
```

**ecg_multilead_record表:**
```sql
CREATE TABLE ecg_multilead_record (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    device_id BIGINT NOT NULL,
    record_name VARCHAR(100),
    lead_count INT DEFAULT 12,
    sample_rate INT DEFAULT 500,
    duration_seconds INT DEFAULT 0,
    data_storage_id VARCHAR(100),
    status VARCHAR(20) DEFAULT 'RECORDING',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id (user_id),
    INDEX idx_device_id (device_id),
    INDEX idx_created_at (created_at),
    INDEX idx_status (status)
);
```

### 5. 技术架构亮点

#### 5.1 时序数据解耦设计

**架构模式:**
```
MySQL (ecg_multilead_record)
  ↓ data_storage_id
InfluxDB/TimescaleDB (实际波形数据)
```

**优势:**
- 关系数据和时序数据分离,各司其职
- MySQL存储元数据,支持复杂查询和事务
- InfluxDB存储高频波形数据,高写入性能
- 通过data_storage_id灵活关联
- 支持未来切换不同的时序数据库

#### 5.2 类型安全查询

**技术实现:**
```java
LambdaQueryWrapper<EcgLeadConfig> wrapper = new LambdaQueryWrapper<>();
wrapper.eq(EcgLeadConfig::getLeadName, leadName)
       .orderByAsc(EcgLeadConfig::getDisplayOrder);
```

**优势:**
- 编译时类型检查,避免字段名拼写错误
- IDE智能提示,提升开发效率
- 重构友好,字段重命名自动更新

#### 5.3 完善的权限控制

**实现机制:**
```java
public void deleteRecord(Long recordId, Long userId) {
    EcgMultiLeadRecord record = multiLeadRecordMapper.selectById(recordId);
    if (record != null && record.getUserId().equals(userId)) {
        multiLeadRecordMapper.deleteById(recordId);
    } else {
        throw new RuntimeException("记录不存在或无权限删除");
    }
}
```

**安全性:**
- 删除操作验证userId匹配
- 防止越权删除他人记录
- 符合医疗数据安全要求

#### 5.4 灵活的状态管理

**状态机:**
```
RECORDING (记录中)
    ↓
COMPLETED (已完成) 或 ERROR (错误)
```

**应用场景:**
- RECORDING: 正在采集数据,前端显示"采集中"
- COMPLETED: 数据采集完成,可进行AI分析
- ERROR: 采集过程出错,需要重新采集
